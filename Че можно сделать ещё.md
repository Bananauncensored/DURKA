Короч заметил что у нас тип:
```json
{
    "wagon_1": 49,
    "wagon_2": 1,
    "wagon_3": 42,    
}
```
Мб можно тип в логике сделать так, чтоб при объёме фоток < 3 либо выкинуть их, либо закинуть в следующий/предыдущий вагон
```Python
 # -------- one_wagon --------
    if cls == "one_wagon":
        current_wagon_photos += 1
        current_wagon_paths.append(img_path)

    # -------- transition --------
    elif cls == "transition":
        if current_wagon_photos > 0: # <---мб тут поменять
            wagon_count += 1
            wagon_photos[f"wagon_{wagon_count}"] = current_wagon_photos
            #<--- мб тут добавить эту логику
            # папка вагона
            wagon_dir = OUTPUT_DIR / f"wagon_{wagon_count}"
            wagon_dir.mkdir(parents=True, exist_ok=True)
```
